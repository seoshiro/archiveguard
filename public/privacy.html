ARCHIVEGUARD · JPEG EDITION 1.0

Your archive stays on your device.

ArchiveGuard is a free browser utility for reviewing a selected sample of JPEG photos and Google Photos JSON sidecars, then exporting verified new copies. It needs no account, paid API, or subscription.

What stays private

Selected photos, JSON contents, filenames, dates, and GPS metadata stay in your browser’s memory. They are not uploaded to the host or sent to analytics. The host serves only app code and bundled synthetic demo assets. Reloading or closing the tab clears the session.

GitHub Pages hosts the public release and may log ordinary website requests, including visitor IP addresses, for security. Those requests do not contain your selected archive. See GitHub’s hosting data collection documentation. Local offline hosting is available from the source repository.

Safe copies and GPS

Original files are never overwritten or deleted. Repair writes DateTimeOriginal and OffsetTimeOriginal to a new JPEG copy and removes capture subseconds. The app verifies supported EXIF values, reads written capture fields with two readers, and compares every JPEG byte outside EXIF. Source and output hashes are recorded separately.

JSON-sidecar GPS is never added. Existing embedded GPS remains in exported JPEGs. Reports omit coordinates, but they contain filenames, dates, and hashes. Treat both copies and reports as private archive data.

Supported scope

  • 200 selected inputs and 64 MiB per batch; 12 MiB per JPEG and 1 MiB per JSON.
  • Unpacked JPEG files and Google Photos JSON sidecars only. ZIP input, HEIC, RAW, video, and full-library processing are unsupported.
  • One reviewed fixed UTC offset per batch. Use separate batches for different offsets or daylight-saving periods.
  • Upload/creation time is shown as evidence and never used as a capture-time fallback.
  • Ambiguous matches, date conflicts, missing offsets, duplicates, and missing sidecars require a decision. No deletion or automatic deduplication.
  • MakerNotes, unknown EXIF tags, malformed metadata, and unsupported layouts disable repair. A readable JPEG may still be kept as a byte-identical copy.
  • JPEG frame and initial scan checks do not prove full image decodability. The app does not repair image corruption, XMP dates, or filesystem timestamps.

Help and source

Start with the synthetic demo, then a small sample. The audit explains every included or excluded input. If an export fails verification, no partial ZIP is offered.

Source and issue tracking: seoshiro/archiveguard. Report the error message, browser, and a synthetic reproduction. Do not attach private photos, real sidecars, GPS coordinates, or private audit reports. Support is best effort for this free project release.

Google Takeout retains original embedded timestamps and supplies extra metadata in JSON. ArchiveGuard compares evidence; it does not assume every file needs repair. This project is independent of Google.
